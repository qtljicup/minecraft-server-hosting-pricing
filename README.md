## MC 吃的是單核，不是核心數

這節是整篇最該記住的部分。Minecraft 的主遊戲執行緒高度依賴單核效能，核心數再多，主執行緒跑不動就是跑不動。1.18 之後的各版本把單核需求拉得更高，第三方作者的原話是：拿一顆 2.9GHz 的老至強去開模組服，TPS 掉到 15 都不奇怪。這句話是他給的，不是本文實測，但方向和 Mojang 版本演進的實際情況一致。

同一份整理給了各機型的 CPU-Z 單核分數，可當作選檔的粗略標尺：

| --- | --- | --- | --- |
| i9-14900K／14900KF | 6.0GHz | 880–900 | 1.20+ 大型模組整合包、50 人以上群組 |
| Ryzen 7950X／9950X | 5.7GHz | 原文稱 Linux 下反超 i9，未給分數 | 高版本插件加模組混開 |
| R9 5900X | 4.8GHz | 450–520 | 中高版本模組、小型群組、基岩版輕量服 |

| E5 2666v3 | 2.9GHz | 未給 | 掛機、低版本小型生存 |

換成可執行的規則：

跑 **1.20 以上的模組整合包**，不論幾個人，先看 i9 14900K／14900KF 或 Ryzen 7000、9000 系，這是單核最強的兩條線。跑 **1.18 到 1.20 的插件服**，Ryzen 5900X 這一檔夠用，人數破 20 再往上加。跑 **1.12 或更舊的模組包**，或只是幾個朋友玩原版生存，Platinum 與 E5 這兩檔的低頻 CPU 反而划算，因為舊版本對單核的壓力小很多。

記憶體不要只看人數。原版生存 5 到 10 人，2G 到 4G 夠；Forge 或 Fabric 的整合包，4G 起跳，8G 比較安穩；這是記憶體，跟 CPU 是兩件事，分開判斷。

## 面板方案還是 VPS：差在你要不要碰指令

雨云的遊戲雲（RGS）和一般雲伺服器（RCS）共用同一批硬體，差別在 RGS 內建自研的 MCSM 面板：一鍵開服、CPU 升降級、自動備份、自帶 MySQL，Paper、Spigot、Forge、Fabric 都是從下拉選單挑。流程是選機型下單、進控制台、在面板選服務端類型、設埠、按啟動，然後把 IP 和埠丟給朋友。

VPS 是裸機。你要自己裝 Java、上傳 jar、寫啟動腳本，好處是自由度大，想裝什麼插件、想改什麼 JVM 參數都行。代價是出問題時沒有人幫你排查。

選面板方案的人常卡在一個地方：NAT 共享 IP 模式需要在面板裡手動轉發 25565 埠。純 MC 服開 15 個埠轉發夠用了，照官方教學做大概兩三步。想要自己的獨立公網 IP，得加錢升級獨立 IP 版，第三方整理提到大約每月 ¥30。這件事在比價時容易被忽略，把它算進去再決定。

還有一個計費細節值得先想清楚：雨云部分機型是按 CPU 實際佔用收「電量費」，第三方提到 9950X／14900K 機型是 0.001 元／電量。閒置時段幾乎不花錢，白天沒人、晚上才熱鬧的私人小服很吃這套；但如果你的服長期滿載，電量費累積起來可能比固定計費還貴。

## 常見問題

**Java 版和 Bedrock 版的朋友能一起玩嗎？**

要靠 Geyser 這類橋接插件。它的支援頁顯示當前支援 Java 26.2 與 Bedrock 26.30 到 26.52；有測試指出 Geyser 在 Paper 26.2 載入成功、在 Paper 26.3 載入失敗，所以部分面板會拒絕在 26.2 以上開啟 Bedrock 橋接。想跨版本同樂，Java 端版本要壓在 26.2 以內。

**Xbox、PlayStation、Switch 的朋友進得來嗎？**

Mojang 的 Bedrock 伺服器頁把主機列為可加入專用伺服器的平台，但 Mojang 幫助中心說主機版只限 featured servers、沒有「Add Server」按鈕，兩處官方說法本身不一致。實務上比較穩的做法是請主機朋友改用平板、手機或 Windows 版連進來。

**有沒有免費方案？**

有，透過積分兌換 E5 2666v3 或 Platinum 8275cl 的免費遊戲雲伺服器，可長期續期。效能只夠跑低版本小型生存或掛機，但零成本試水溫很合適。

**退款怎麼算？**

7 天內可申請，但依第三方整理的說法有次數限制（約三次），而且退到帳戶餘額，不能提現到支付寶或微信。試之前先想清楚要試哪個方案。

**換方案會不會丟世界？**

面板方案走的是同一套儲存，升級 CPU、記憶體一般不影響存檔；VPS 方案換機型要自己搬檔案。這是「面板比 VPS 省事」的另一個具體理由。
